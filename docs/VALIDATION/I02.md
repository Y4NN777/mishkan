## Observed mechanism result

The tested initialization path follows the required lifecycle:

1. CrewAI proposes the repository-specific plan.
2. Deterministic validation resolves an immutable tool-registry snapshot, exact task and reviewer
   bindings, policy decisions, and approvals before accepting plan version 1.1.
3. CrewAI Agents and Tasks receive only `GatewayCrewAITool` instances built from that accepted
   lineage.
4. The fixed capability gateway validates schemas and resolved targets, evaluates public policy,
   resolves credentials late, dispatches the configured adapter, inspects the complete result, and
   persists non-secret decision lineage.
5. Deterministic result verification precedes an independent downstream CrewAI review under a
   different role; final acceptance and outbox persistence remain MISHKAN-owned.

The obsolete I01 direct file tool and registry were removed, so the tested path has one tool path.

rules, sources, and tool compositions are visible versioned configuration rather than a private
action list.

do not validate the current bundled source as the SWE organization catalogue. In particular,
