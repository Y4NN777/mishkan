# MISHKAN

MISHKAN is currently in pre-implementation product and systems planning.

The repository intentionally contains no application implementation. Planning follows the
[SWE-BASICS-BEFORE-CODE](https://github.com/MatrixCollab/SWE-BASICS-BEFORE-CODE)
method:

> Intent → Requirement → Contract → Responsibility → Architecture → Code

Durable project documentation starts at [`docs/README.md`](docs/README.md). The canonical product
authorities are `docs/PROJECT/PRD.md`, `docs/PROJECT/SRS.md`, and the central decision log.

Working notes and review checklists are not stored as project documents. No implementation begins
until the engineer explicitly approves the remaining design sequence and implementation plan.
